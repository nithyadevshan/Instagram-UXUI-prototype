📸 Instagram Mobile App UI/UX Prototype
Overview
This project is an Instagram-inspired mobile application prototype designed using Figma. The prototype focuses on creating an intuitive and visually appealing user experience by replicating key Instagram functionalities, including user authentication, home feed navigation, profile management, messaging, and interactive user flows.

Project Highlights
Interactive mobile app prototype
User-friendly login experience
Instagram-style home feed
Stories interface
Explore/Search functionality
User profile screens
Messaging and chat interface
Seamless screen-to-screen navigation
Mobile-first design approach
